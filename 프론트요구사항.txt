프론트엔드 구현 요구 사항
프로젝트 목표
AI Agent의 도움을 받아 React 기반 숙소예약 프로젝트의 프론트엔드를 구현한다.

프론트엔드 완성도 자체보다 백엔드 API를 실제 화면에서 사용해 보고, HTTP, 인증, 상태 관리, 비동기 처리 흐름을 체득하는 것을 목표로 한다.

JavaScript와 React 경험이 적다는 전제를 두고, 처음부터 복잡한 구조를 만들기보다 작은 기능을 완성하고 점진적으로 개선한다.

프론트엔드는 백엔드 기능을 검증하고 시연할 수 있는 수준을 우선 목표로 하며, 디자인은 제공된 Figma를 참고하되 100% 픽셀 퍼펙트를 요구하지 않는다.

학습 목표
JavaScript 기본 문법을 프로젝트 코드 안에서 익힌다.

React 컴포넌트, props, state, effect의 역할을 이해한다.

화면을 URL 단위로 나누고 React Router로 페이지 이동을 구현한다.

Fetch API를 사용해서 데이터를 호출하고, 로딩(필요시), 성공, 실패 상태를 화면에 표현한다.

로그인 상태와 사용자 정보를 프론트엔드에서 다루는 방법을 경험한다.

백엔드 API 명세를 읽고 프론트엔드 요청 형식으로 옮기는 연습을 한다.

AI Agent에게 작업을 맡길 때 요구사항을 작게 나누고, 생성된 코드를 읽고 수정하는 연습을 한다.

AI Agent가 만든 컴포넌트도 팀원이 직접 읽고 설명할 수 있어야 한다.

상태 관리 요구 사항
기본적으로 React의 useState, useEffect를 사용한다.

전역 상태 라이브러리는 필수가 아니다.

로그인 사용자 정보처럼 여러 화면에서 필요한 데이터는 Context API 사용을 고려한다.

서버 데이터 캐싱이 필요하면 TanStack Query 도입을 선택할 수 있다.

단, 도입한 팀은 왜 필요한지 README에 간단히 설명한다.

API 연동 요구 사항
API 요청과 화면 코드를 분리한다.

백엔드 API 명세를 기준으로 프론트엔드에서 필요한 요청, 응답 예시를 정리한다.

API 오류 응답을 무시하지 않고 사용자에게 적절히 표시한다.

401, 403 응답을 구분해서 처리한다.

401: 로그인이 필요함

403: 권한이 없음

POST, PUT, DELETE 요청 후에는 관련 목록 또는 상세 데이터를 다시 가져온다.

날짜, 금액, 인원 수 같은 값은 프론트엔드와 백엔드의 형식을 맞춘다.

AI Agent 사용 요구 사항
AI Agent는 구현 보조 도구로 사용하되, 생성된 코드를 그대로 제출하지 않는다.

기능을 한 번에 크게 요청하지 말고 작은 단위로 요청한다.

좋은 예: "숙소 목록 API 응답을 받아 RoomCard 목록으로 렌더링하는 컴포넌트를 만들어줘"

나쁜 예: "Airbnb 프론트 전체를 만들어줘"
